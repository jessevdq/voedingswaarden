# Voedingswaarden
Persoonlijke zoek-app voor caloriën en macro's van standaardproducten.
Bron: NEVO-online versie 2025/9.0, RIVM, Bilthoven (gegevens ongewijzigd overgenomen). Vlaamse zoektermen en iconen zijn eigen toevoegingen.

Bestanden: `index.html` (app), `data.js` (NEVO-data), `sw.js` (offline cache), `manifest.json` + iconen (installeerbaar als app).
